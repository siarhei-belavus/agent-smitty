# Domain Model Delta

A Domain Model Delta is a compact, self-contained, document-ready record of a confirmed domain-language or architecture change. Ordinary implementation decisions remain in planning authority.

`**D<n>. <Name>.** <Exact change and the semantics needed to apply it>. Route: <Repository ID>:<canonical pointer> | planning only. Source: <permanent reference or accepted conversation>.`

Include a definition, invariant, boundary, relationship, rationale, counterexample, or contradiction condition only when its loss would change how the delta is applied. Split only when owner or route differs. `planning only` changes no canonical artifact.
