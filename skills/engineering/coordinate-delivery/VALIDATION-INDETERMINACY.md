# Validation Indeterminacy

Validation Indeterminacy exists when planned human-verification evidence cannot decide pass or fail against the declared criteria.

Keep the current Execution Checkpoint. Complete and supersede the planned-verification request, then create one linked escalation-bearing successor through the [Human Action Request contract](../federated-workflow/LIFECYCLE-ARTIFACTS.md#human-action-request). State the exact missing evidence or clarification and preserve the response as observed.

Re-read the chain and remain at the [human boundary](HUMAN-BOUNDARY.md). Inference never converts indeterminacy into pass, fail, `continue`, or `replan`.

**Complete when:** the planned request is superseded, exactly one linked escalation request is active against the same checkpoint, and no Execution Attempt has begun.
