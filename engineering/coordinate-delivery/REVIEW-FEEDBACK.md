# Actionable Review Feedback

Re-read the affected Review Proposals and enumerate attributable feedback by permanent provider ID. Return the open ticket to unassigned `ready-for-agent` through human authority, then return to the [Resume Gate](RECOVERY.md) with Review Feedback qualified as the sole source.

At the Resume Gate, reassemble the checkpoint's fixed Delivery Context selection from provider truth. Do not change its activation-ticket root or profile. When assembly stops, enter the human boundary. The accepted output becomes the recovered attempt's Authority input.

Reuse each affected delivery's existing Review Proposal. Launch fresh affected Implementation Agents from the checkpoint with the refreshed Authority input. For each changed head, refresh repository validation and pass that same input to `code-review` in **Standards only** mode. Rerun every invalidated obligation with fresh Validation Agents, then pass it to `code-review` in **Spec only** mode over the complete affected target set. Repeat the correction and fresh-review sequence until clean or a genuine human boundary applies. Preserve proposals and only the evidence that remains current under [Recovery's complete dependency rule](RECOVERY.md).

**Complete when:** every implementation and review input preserves the refreshed Authority input, every actionable item has an attributable disposition, each affected proposal points to its refreshed exact head, all dependent evidence is current, and no duplicate proposal exists.
