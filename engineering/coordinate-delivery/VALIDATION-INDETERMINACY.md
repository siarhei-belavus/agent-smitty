# Validation Indeterminacy

Read this file when a Human Response to planned verification and bounded follow-up diagnosis cannot determine whether the declared obligation passed or failed.

Keep the current Execution Checkpoint. Complete and supersede the planned-verification request, then create one linked escalation-bearing successor through the [Human Action Request contract](ARTIFACTS.md#human-action-request). State the exact missing evidence or clarification and preserve the response as observed.

Re-read the chain and remain at the [human boundary](HUMAN-BOUNDARY.md). Inference never converts indeterminacy into pass, fail, `continue`, or `replan`.

**Complete when:** the planned request is superseded, exactly one linked escalation request is active against the same checkpoint, and no Execution Attempt has begun.
